# Voronoi Map Generator (Unity ECS)

Высокопроизводительный процедурный генератор карт на основе диаграмм Вороного, использующий **Unity ECS (DOTS)**, **Burst Compiler** и **C# Job System**. Проект генерирует иерархический ландшафт с симуляцией тектоники, климата и гидрологии.

## 🚀 Основные возможности

*   **DOTS Архитектура:** Полностью построен на ECS. Логика генерации (тектоника, климат) и создание мешей (Terrain, Rivers) выполняются в многопоточных Burst Jobs.
*   **Иерархическая генерация:** Поддержка уровней детализации (L0 - Глобальный, L1 - Региональный, и т.д.).
*   **Dynamic LOD System:** Автоматическое переключение геометрии и детализации в зависимости от высоты камеры.
*   **Гидрология:** Симуляция стока воды, образование рек, озер и дельт при впадении в океан.
*   **Геометрический Батчинг (Chunking):** Тысячи ячеек Вороного объединяются в единые чанки (меши) для минимизации Draw Calls (10k+ ячеек рендерятся за <1ms на GPU).
*   **Процедурное текстурирование:** Использование Vertex Colors для смешивания биомов в шейдере.

## 🎮 Управление (Команды)

Камера управляется компонентом `MapCameraBootstrap` и системой `CameraControlSystem`.

| Команда / Клавиша | Действие |
| :--- | :--- |
| **W, A, S, D** / Стрелки | **Панорамирование:** Перемещение камеры над картой в плоскости XZ. |
| **Колесо Мыши (Scroll)** | **Зум (Приближение/Отдаление):** Изменяет высоту камеры. Влияет на систему LOD (чем ближе, тем выше детализация). |
| **Q** | **Вращение влево** вокруг точки фокуса. |
| **E** | **Вращение вправо** вокруг точки фокуса. |
| **Правя кнопка мыши (Удержание)** | **Свободный обзор:** Вращение камерой мышью (Look Around). |

## ⚙️ Настройка и Генерация

Все настройки находятся на объекте сцены с компонентом `MapGeneratorBootstrap`:

### 1. General Settings
*   **Seed:** Сид генерации. Нажмите кнопку **"Dice"** для случайного числа.
*   **Map Size:** Размеры мира (например, 1000x1000).
*   **Terrain Height Scale:** Глобальный множитель высоты рельефа.

### 2. Level Configurations (LODs)
Здесь задаются параметры для каждого уровня иерархии (L0, L1, L2):
*   **Max Site Count:** Количество ячеек Вороного для данного уровня.
*   **LOD Threshold:** Высота камеры, при которой этот уровень включается.

### 3. Visual Styles
*   **Height Scale:** Высота гор для конкретного уровня.
*   **Bottom Depth:** Насколько глубоко уходит "земля" вниз (избегайте 0, ставьте 50+, чтобы не было дырок).
*   **River Width:** Множитель ширины рек.
*   **Meander Params:** Параметры извилистости русла (амплитуда и частота шума).
*   **Texture Scale:** Масштаб тайлинга текстур (UV) для чанков.

### 4. Render Visibility
*   **Use Auto LOD:** Если включено — слои переключаются сами при зуме. Если выключено — можно вручную включать чекбоксы уровней (L0, L1, L2).
*   **Show Rivers:** Вкл/Выкл генерацию рек.

### 🛠 Кнопка "FORCE REBUILD"
В самом низу инспектора. Нажмите её в Play Mode, чтобы перегенерировать мир с новыми настройками (сид, параметры рек, визуальный стиль).

## 📦 Технические Требования

*   **Unity Version:** 2022.3 (LTS) или выше (Рекомендовано 2023+).
*   **Render Pipeline:** URP (Universal Render Pipeline). Шейдеры используют Vertex Colors (`Particles/Lit` или кастомный Shader Graph).
*   **Packages:**
    *   `com.unity.entities`
    *   `com.unity.collections`
    *   `com.unity.mathematics`
    *   `com.unity.burst`
    *   `com.unity.render-pipelines.universal`
